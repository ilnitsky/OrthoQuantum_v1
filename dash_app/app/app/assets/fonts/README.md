# Interface font

JetBrainsMono Nerd Font, regular and bold, from Nerd Fonts v3.3.0.
Upstream JetBrains Mono version: 2.304.

Font files:
- https://github.com/ryanoasis/nerd-fonts/tree/v3.3.0/patched-fonts/JetBrainsMono/Ligatures

Licenses:
- `JetBrainsMono-OFL.txt`: upstream SIL Open Font License.
- `NerdFonts-LICENSE.txt`: Nerd Fonts project license notices.

The fonts are served locally through Dash assets. `typography.css` defines the
shared family, including forms, tables and interactive SVG labels. Icon fonts
keep their own families. Already-rendered PNG images contain their own lettering;
CSS cannot replace those embedded glyphs.
