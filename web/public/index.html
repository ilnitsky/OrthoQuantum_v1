Model and assumptions

One origin at the last common ancestor of observed presences; maximal all-absent descendant clades count once. Only exactly matching branches count as shared holes. Undated edges and BLAST-pending clades are skipped. p(g,b) = 1 − exp(−h × evolrate(g) × branch length / tree height). Weight = −ln(max(10⁻⁶,p)) / tipsᵅ. S = sum of mean shared weights × √(shared events) × weighted overlap. Overlap penalizes unmatched holes. Missing evolutionary rates use 1, reported explicitly. Sequence evolutionary rate is not a measured loss rate: h and the linear rate coupling are model assumptions. Score is a ranking heuristic, not a p-value or proof of functional coupling. Missing annotations can mimic losses; independent branches under this reconstruction are not proof of independent historical events.

About OrthoQuantum
OrthoQuantum is a web-based tool for visualizing and studying phylogenetic presence/absence patterns of proteins and corresponding orthologous groups.
OrthoQuantum allows users to submit protein queries, inspect the output in graphic format and download the output in CSV format. The tool visualizes phylogenetic profiles using databases with orthology predictions.
